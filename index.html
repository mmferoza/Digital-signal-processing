PROGRAM 1 – Generation of Discrete-Time Signals

Generation of Unit Sample, Unit Step, Exponential, Sinusoidal and Random Sequences

🎯 Aim

To generate and visualize Unit Sample, Unit Step, Exponential, Sinusoidal and Random discrete-time sequences.

📖 Theory

Unit Sample: δ[n] is 1 at n=0 and 0 elsewhere.

Unit Step: u[n] is 1 for n≥0 and 0 for n<0.

Exponential: x[n]=an.

Sinusoidal: x[n]=A sin(ωn+φ).

Random Sequence: a sequence whose values are generated randomly.

⚙️ Algorithm

  1. Start.
  2. Define the required time index.
  3. Generate the required sequence.
  4. Plot the sequence.
  5. Add labels, title and grid.
  6. Stop.

1.1 Unit Sample Sequence

clc ;

stem(n, delta);

ylabel('\delta[n]');

PROGRAM 2 – Operations on Signals

Signal Addition, Multiplication, Scaling, Shifting and Folding

🎯 Aim

To perform basic operations on discrete-time signals including addition, multiplication, scaling, shifting and folding.

📖 Theory

Addition: y[n]=x₁[n]+x₂[n].

Multiplication: y[n]=x₁[n]x₂[n].

Scaling: y[n]=a x[n].

Shifting: signal position is changed along the time axis.

Folding: y[n]=x[-n].

⚙️ Algorithm

  1. Define or enter the signals.
  2. Perform the required operation.
  3. Plot original and resultant signals.
  4. Observe the output.

PROGRAM 3 – Linear Convolution

Convolution of Two Given Sequences Without Using Built-in Function

🎯 Aim

To compute the linear convolution of two sequences without using MATLAB's built-in conv() function.

📖 Theory

For an LTI system, the output is obtained by convolution: y[n]=x[n]*h[n]. If the lengths are N₁ and N₂, the output length is N=N₁+N₂−1.

⚙️ Algorithm

  1. Enter x[n] and h[n].
  2. Find their lengths.
  3. Initialize output to zero.
  4. Use nested loops to perform convolution.
  5. Plot the input sequences and output.
  6. Display the result.

Linear Convolution

clc;
clear all;
close all;

x = input('Enter x = ');
h = input('Enter h = ');

N1 = length(x);
N2 = length(h);

N = N1 + N2 - 1;

y = zeros(1,N);

for n = 1:N
    for k = 1:N1
        if (n-k+1 >= 1) && (n-k+1 <= N2)
            y(n) = y(n) + x(k)*h(n-k+1);
        end
    end
end

n = 0:N-1;

figure;

subplot(3,1,1);
stem(0:N1-1,x,'filled');
xlabel('n');
ylabel('x[n]');
title('Input Signal x[n]');
grid on;

subplot(3,1,2);
stem(0:N2-1,h,'filled');
xlabel('n');
ylabel('h[n]');
title('Impulse Response h[n]');
grid on;

subplot(3,1,3);
stem(n,y,'filled');
xlabel('n');
ylabel('y[n]');
title('Output Signal y[n] = x[n] * h[n]');
grid on;

disp('Linear Convolution Result:');
disp(y);

PROGRAM 5 – Properties of Convolution

Verification of Commutative, Associative and Distributive Properties Using FFT

🎯 Aim

To verify the commutative, associative and distributive properties of convolution using FFT.

📖 Theory

Commutative: x*h=h*x.

Associative: (x*h₁)*h₂=x*(h₁*h₂).

Distributive: x*(h₁+h₂)=x*h₁+x*h₂.

FFT converts convolution into multiplication in the frequency domain.

Verification Using FFT

clc; clear all; close all;

% Input sequences
x = input('Enter the first sequence: ');
h1 = input('Enter the second sequence: ');
h2 = input('Enter the third sequence: ');
N = input('Enter the length: ');

% Perform FFT on the sequences
X = fft(x,N);
H1 = fft(h1,N);
H2 = fft(h2,N);

% Commutative property
Y1 = X .* H1;
Y2 = H1 .* X;

y1 = ifft(Y1);

subplot(3,2,1);
stem(real(y1));
grid on;
xlabel('Time');
ylabel('Magnitude');
title('y1: X .* H1');

y2 = ifft(Y2);

subplot(3,2,2);
stem(real(y2));
grid on;
xlabel('Time');
ylabel('Magnitude');
title('y2: H1 .* X');

disp('y1:');
disp(y1);
disp('y2:');
disp(y2);

if isequal(y1,y2)
    disp('Commutative property is verified.');
else
    disp('Commutative property is not verified.');
end

% Associative property
Y3 = (X .* H1) .* H2;
y3 = ifft(Y3);

subplot(3,2,3);
stem(real(y3));
grid on;
xlabel('Time');
ylabel('Magnitude');
title('y3: (X .* H1) .* H2');

Y4 = X .* (H1 .* H2);
y4 = ifft(Y4);

subplot(3,2,4);
stem(real(y4));
grid on;
xlabel('Time');
ylabel('Magnitude');
title('y4: X .* (H1 .* H2)');

disp('y3:');
disp(y3);
disp('y4:');
disp(y4);

if isequal(y3,y4)
    disp('Associative property is verified.');
else
    disp('Associative property is not verified.');
end

% Distributive property
Y5 = X .* (H1 + H2);
Y6 = X .* H1 + X .* H2;

y5 = ifft(Y5);
subplot(3,2,5);
stem(real(y5));
grid on;
xlabel('Time');
ylabel('Magnitude');
title('y5: X .* (H1 + H2)');

y6 = ifft(Y6);
subplot(3,2,6);
stem(real(y6));
grid on;
xlabel('Time');
ylabel('Magnitude');
title('y6: X .* H1 + X .* H2');

disp('y5:');
disp(y5);
disp('y6:');
disp(y6);

if isequal(y5,y6)
    disp('Distributive property is verified.');
else
    disp('Distributive property is not verified.');
end

PROGRAM 9 – Parseval's Theorem of DFT

Verification of Parseval's Theorem using DFT

🎯 Aim

To verify Parseval's theorem using two input sequences and their DFTs.

📖 Theory

Parseval's relation is Σx₁[n]x₂*[n]=(1/N)ΣX₁[k]X₂*[k]. It relates the inner product in time domain to the normalized inner product in frequency domain.

Parseval's Theorem

clc;
clear all;
close all;

x1=input('enter the 1st input seq=');
x2=input('enter the 2nd input seq=');

N=4;

X1=fft(x1,N);
X2=fft(x2,N);

y1=sum(x1.*conj(x2));
y2=sum(X1.*conj(X2))./N;

if y1==y2
    disp('parsevals theorem proved');
else
    disp('parsevals theorem not proved');
end

PROGRAM 10 – Butterworth Low-Pass IIR Filter

Design of a Butterworth Low-Pass IIR Filter Using MATLAB

🎯 Aim

To design a Butterworth low-pass IIR filter using buttord() and butter() and obtain its frequency response using freqz().

📖 Theory

The Butterworth filter has a maximally flat passband. The normalized frequencies are Wp=fp/(fs/2) and Ws=fstop/(fs/2). MATLAB's buttord() determines the minimum order and butter() designs the filter.

Butterworth Low-Pass Filter

clc; clear all; close all;

fs=input('Enter fs= ');

ks=input('Enter ks= ');
fp=input('Enter fp= ');
fstop=input('Enter fstop= ');

wp=fp/(fs/2);
wstop=fstop/(fs/2);

[N wc]=buttord(wp,wstop,kp,ks)

[b a]=butter(N,wc,'low');

freqz(b,a,1000,fs);

PROGRAM 15 – Sampling Theorem

Continuous-Time and Discrete-Time Representation of a Sinusoidal Signal for Different Sampling Frequencies

🎯 Aim

To study the effect of sampling frequency on a sinusoidal signal and observe the sampled signal for different values of fs relative to 2fm.

📖 Theory

According to the sampling theorem, a band-limited signal of maximum frequency fm can be reconstructed without aliasing when the sampling frequency satisfies fs ≥ 2fm. The three important cases are under-sampling, Nyquist-rate sampling, and over-sampling.

⚙️ Observation

  1. The continuous-time cosine signal is first generated.
  2. The signal is sampled at different sampling frequencies.
  3. The sampled values are displayed using stem plots.
  4. The plots show how the sampling frequency affects the representation of the original signal.

Sampling Theorem – Four Plots

clc;

clear all;

t=-100:01:100;

fm=0.01;

x=cos(2*pi*t*fm);

subplot(2,2,1)
plot(t,x);
xlabel('time in sec');
ylabel ('x(t)');
title ('continuous time signal ');

fs1=0.02;
n=-2:2;
x1=cos(2*pi*fm*n/fs1);
subplot(2,2,2);
stem(n,x1);
hold on;
subplot(2,2,2);
plot(n,x1,':');
title('discrete time signal x(n) with fs<2fm');
xlabel('n');
ylabel('x(n)');

fs2=0.04;
n1=-4:4;
x2=cos(2*pi*fm*n1/fs2);
subplot(2,2,3);
plot(n1,x2,':');
stem (n1,x2);
hold on;
